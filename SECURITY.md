# Security Policy

## Supported Versions

Current supported versions based on when the project was made, and what security updates exist.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | Always             |
| > Build 8th to 12th of November 2026   | :white_check_mark:                |
| Build 8th to 12th of November 2026   | :white_check_mark: |
| < Build 8th to 12th of November 2026   | :x:                |

 - https://github.com/eyecantsee-roblox-lua-obfuscated/EyeTrainerCDDZ/issues

or

  - https://github.com/eyecantsee-roblox-lua-obfuscated/EyeTrainerCDDZ/discussions

Expect a update every day, week or if worst case ensues, every month.
